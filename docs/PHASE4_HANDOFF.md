1. Obtain explicit production-cutover and DNS/custom-domain/indexing authorization.
2. Confirm clinic NAP, registration, hours, GBP consistency and privacy policy.
3. Renew restricted/source-scope reviews and approve any substantive clinical additions.
4. Confirm whether WhatsApp remains primary; supply/validate Google Form and update privacy text only if activating it.
5. Obtain complete legacy/indexed URL/backlink exports and approve mapping; resolve gallery absence.
6. Prepare backups, rollback, domain/TLS/Cloudflare proxy and approved response headers.
7. Build root output; review intentionally thin noindex categories and final submitted sitemap.
8. Validate production URLs/assets, real 404, all ten videos, WhatsApp, links, schema and mobile behavior.
9. Activate only approved edge redirects; check chains and exact destinations.
10. Separately approve production indexing; change production flag only after launch checks and check robots/meta consistency.
11. Configure actual Search Console/Bing values and verify ownership; submit production sitemap, never preview.
12. Decide consent-aware aggregate measurement; don't enable automatic health-path or form tracking.
13. Monitor actual crawl/index coverage, redirects, field Core Web Vitals and observed AI citations without guarantees.

Stop after Phase 4. This checklist does not authorize Phase 5 or any infrastructure change.
