A robots file at `/drvasundara/robots.txt` is not the host-root robots file recognized by search engines. GitHub account-root policy is outside this project. Every preview HTML page therefore carries its own noindex; canonical intent is not a noindex substitute. Robots disallow is a crawl control, not a reliable deindexing instruction for an already discovered URL. No preview URL is submitted to engines.

`urls.ts` remains intact. Existing preparation handles href/src prefixes; Astro handles imported assets and responsive source sets. New checks also inspect srcset, CSS font/image references, raster social URLs, all sitemap destinations, external new-tab rel safety and stable schema IDs. One H1, unique titles/descriptions and JSON-LD syntax remain checked by existing tests. A Testimonials heading skip was corrected with a hidden H2.

Root/proxy canonical verification is lexical: each generated page canonical equals `https://drvasundaragynec.com` plus its normalized route. The 404 artifact deliberately has `/404/` canonical intent, is absent from the sitemap, and must return actual HTTP 404 for unknown paths after deployment.

Thin categories remain useful navigation pages and independently noindex where they contain fewer than two articles. They currently remain in the build sitemap; exclude these intentionally noindex categories from the final production submission if they are still thin. No indexing switch was enabled.
